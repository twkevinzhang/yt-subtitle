# AI 歌詞字幕

桌面 Chrome／Brave 的 YouTube 歌詞擴充功能。使用自己的 AI 服務尋找歌詞，再用 YouTube 字幕對齊；支援貼上歌詞、匯入 LRC／SRT、逐句校時、原文／雙語／譯文、保存與 SRT 下載。

**目前是可本機載入的第一版，尚未上架商店。** 合成資料與本機假 AI 的 Brave 端到端流程已驗證；真實 YouTube 已驗證按鈕與字幕軌發現，但測試影片字幕端點回傳空內容，字幕內容擷取尚未通過。真實 AI server 搜尋與對齊尚未驗收，不宣稱安裝後所有影片都可自動同步。詳見 [驗證紀錄](docs/verification.md)。

## 安裝

1. 使用專案根目錄的 `dist/`；或將 `artifacts/ai-lyrics-extension.zip` 解壓縮到固定位置。
2. Chrome 開啟 `chrome://extensions`；Brave 開啟 `brave://extensions`。
3. 開啟「開發人員模式」，選「載入未封裝項目」，選擇含 `manifest.json` 的目錄。
4. 開啟或重新整理一般 YouTube 影片，在播放器控制列點 **AI**，工作面板位於右側推薦欄頂部（劇院模式在影片右下方，一般模式在影片右側），推薦影片順延至面板下方，左側操作與設定，右側整段歌詞可獨立捲動。尚未設定時自動展開，右側顯示影片資訊及設定引導。

更新時重新建置，再到擴充功能頁按重新載入，重新整理 YouTube。移除擴充功能會清除其本機設定及資料；請先下載重要 SRT。

## 設定自己的 AI 服務

在設定頁填入：

- Base URL，例如 `https://your-service.example/v1`。程式會附加 `/models` 或 `/chat/completions`，不要填完整 chat 路徑。
- API Token、模型名稱。
- 若服務受 Cloudflare Access 保護，成對填入 Client ID、Client Secret。
- 勾選允許搜尋的歌詞網域，或新增自訂名稱與網域。預設提供 LRCLIB；自訂子網域需另行勾選。

按「儲存設定」時，瀏覽器會要求連線到該服務的權限。接著可「測試連線／載入模型」。設定頁的所有測試使用已儲存值；修改欄位後要先儲存。

未設定 AI 時不顯示搜尋，AI 對齊／翻譯停用；貼上、匯入、手動校時、套用與匯出仍可使用。儲存完整設定後啟用 AI 並保留草稿。每次載入影片或設定更新，背景查詢一次模型列表（8 秒逾時、不自動重試、不生成文字）；連線失敗不阻擋本機功能，實際 AI 操作失敗時才提示。

工作面板跟隨 YouTube 明暗外觀，設定頁跟隨瀏覽器偏好。右欄顯示原文／雙語／譯文；有時間碼的歌詞可點擊跳轉，播放中的句子會標示。左側逐句校時與右側歌詞各自捲動。全螢幕時影片保留疊加字幕；編輯面板在推薦欄，離開全螢幕後操作。

AI server 必須自己提供網頁搜尋能力；OpenAI 相容文字 API 並不自動包含搜尋工具。第一版通用 adapter 透過自然語言要求服務端搜尋，不會在本機另建爬蟲或搜尋服務。不支援專用工具協定的 server 可能無法搜尋。模型提供來源 URL 仍不是已執行即時搜尋的證據，通用介面結果標示「尚未驗證」，由使用者查核與選擇。

「測試搜尋」會另行確認並使用模型額度。憑證保存在本機擴充功能儲存，限制可信上下文讀取，不同步、不傳給 YouTube、不放進模型 prompt 或 SRT；這不是加密保險箱，請使用可獨立撤銷的 Token。

## 操作

1. 點 AI 開啟面板。發現字幕軌後必須取得有效內容，才會顯示「已讀取 N 段字幕」。可切換人工／自動字幕軌後重新讀取。
2. 搜尋：先查看即將傳送的影片資訊與來源，按「開始搜尋」。選擇歌詞版本；無全文時開啟來源，取得歌詞再貼入。
3. 或直接貼上逐行歌詞、匯入 UTF-8 TXT／逐句 LRC／SRT。上限 2 MiB、10,000 句；逐字 LRC 尚不支援。
4. 有有效 YouTube 字幕時可按「對齊／生成譯文」。第二次確認會顯示要傳送的歌詞、字幕及目標語言。已有時間碼可以僅翻譯，不重新對齊。
5. 預覽每句時間及譯文。錨點沿用字幕時間；估算時間標示待校時；未對齊行須手動設定或排除。可用影片目前位置設起迄，或調整整體偏移（正數延後）。
6. 選擇原文、雙語或僅譯文，按「套用並保存」；關閉面板後字幕繼續顯示。若與 YouTube 原生 CC 重疊，請自行關閉 CC；擴充功能不擅自改變原生 CC 選擇。
7. 「下載 SRT」依目前模式匯出，包含已套用偏移。可在本機版本區重新載入；重開已存結果不呼叫模型。

## 失敗與限制

- 字幕網址可能需要 YouTube 執行時參數，且會隨平台更新改變。可先啟用 CC 再重新讀取；HTTP 200 空內容仍算失敗。無法取得時使用 LRC／SRT 或手動校時，不會憑空生成準確時間。
- 沒有原生字幕且貼入無時間歌詞時，只能手動校時；第一版不擷取音訊或連接音訊服務。
- 不同 live／cover／剪輯版本會有不同節奏，使用者必須核對候選；不能假設同歌名的時間碼適用。
- 翻譯未齊全時不允許雙語／僅譯文匯出。部分句子重疊時提示核對；無效時間、未對齊且未排除的行會阻止套用及匯出。
- 單一 run 全域序列執行，單 request 最長 120 秒，整次最長 10 分鐘／20 次請求；每批最多 40 行，超過安全內容量會提示手動處理。不自動重試。
- 取消中止本機請求並忽略遲到結果，但不保證服務端已開始計費的運算撤銷。MV3 背景程序被瀏覽器停止時顯示中斷，由使用者重試。
- 背景重啟用的工作快照最多 256 KiB，僅保留最新一份；更大的生成結果仍可在目前工作階段立即保存，若背景先被停止則需重新處理。已保存的歌詞結果存於獨立的 IndexedDB，不受此快照限制。
- 限一般 watch 頁；不支援手機、Firefox、Shorts、直播、嵌入式影片、原生子母畫面、逐字卡拉 OK。影片本體的硬字幕無法移除。
- 首版只保存本機結果，100 MiB 軟上限；不自動刪除手動成果，不提供帳號或雲端同步。

## 開發與驗證

需要 Node.js 及 npm。使用鎖定依賴：

```powershell
npm ci
npm test
npm run typecheck
npm run build
npm run test:e2e
npm run package
```

`dist/` 為正式載入目錄，ZIP 位於 `artifacts/`。建置輸出不含測試 fixture、測試用 Token 或 localhost 必要權限；localhost 僅為使用者自選服務的 optional 權限。E2E 另複製測試 manifest 到忽略目錄，授權 localhost 本機假服務，避免無頭瀏覽器的原生權限對話框；這不代表正式逐站權限對話框已自動化驗收。

E2E 預設使用 Windows 已安裝的 Brave，可用 `TEST_BROWSER` 指定另一個 Chromium 瀏覽器執行檔。使用獨立暫存 profile，不連接使用者現有登入瀏覽器。測試伺服器結束即關閉。`node scripts/smoke-youtube.mjs` 是有界的真實 YouTube 唯讀檢查，不需要 AI 憑證，不會下載影片或變更帳號。

程式為原創實作；asbplayer 僅作架構與行為參考，未複製其 AGPL 程式。相依套件保留各自授權。
