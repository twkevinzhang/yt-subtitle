# AI 歌詞字幕

桌面 Chrome／Brave 的 YouTube 字幕擴充功能。三個入口為 **AI 找字幕、YT 字幕、貼入字幕**。任何來源的有效時間碼均保留，只以本機 WASM＋Web Worker 補齊缺少的時間；音訊不傳給 AI server。

目前為可本機載入的開發版本。三入口、保存／匯出與實際 WASM 流程已可驗證；歌曲辨識仍有重要限制：既有真實歌曲片段只辨識出「Yeah」，因此保留待處理，不能宣稱所有歌曲皆能即時同步。詳見[本次整合驗收](docs/validation/2026-10-21-subtitle-integration.md)。

## 安裝與更新

1. 建置後，Chrome 開啟 `chrome://extensions`；Brave 開啟 `brave://extensions`。
2. 開啟開發人員模式，載入未封裝項目，選擇專案 `dist/`；也可先解壓 `artifacts/ai-lyrics-extension.zip`。
3. 重新整理 YouTube 一般 watch 頁，在控制列點「AI 歌詞」。面板預設收起，位於推薦欄頂部；劇院模式保留既有放置行為。
4. 更新程式後重新載入擴充功能並重新整理影片。移除擴充功能會清除本機設定與結果，請先下載重要 SRT。

最低 Chromium 116；目前自動化完整 MV3 驗證使用 Brave。已安裝 Chrome 不接受測試的載入擴充功能旗標，Chrome 僅驗證原生增量 codec，尚未完成 Chrome MV3 介面驗收。

## 三個入口

- **AI 找字幕**：一次真實點擊立即發送三路獨立搜尋，各最多一次，群組上限 120 秒，不自動重試。分別查設定來源、目前 YouTube 影片留言、全網。候選分開呈現，必須由使用者選一份。未設定來源只略過來源那一路；其他路徑不受設定網域限制。沒有全文的候選不可採用。
- **YT 字幕**：僅使用人工且非自動翻譯字幕；可用時呈紅色，只有自動字幕或無字幕則禁用。依目前選取人工軌、目標語言完全符合、主要語言符合、第一份人工軌選取，可從選單切軌。讀取失敗保留原有成果，不改用自動字幕。
- **貼入字幕**：貼入純文字、逐句 LRC 或 SRT 文字，保留換行。上限 2 MiB／10,000 句。沒有檔案匯入入口；仍可下載 SRT。

有效起點或終點分別鎖定，重試與切模式只補缺端點。最後一句 LRC 若缺終點會保留待處理。來源時間重疊只提示，不自動重排；無效時間、缺時且未排除的句子會阻止完整保存與匯出。無法定位不會刪句、改寫歌詞、平均分配時間或暗中呼叫 AI 估時。

## 三種校時模式

設定頁可獨立儲存顯示與校時設定，無須先設定 AI。

| 模式 | 行為 |
| --- | --- |
| 先緩衝再播放（預設） | 初始目標 15 秒，持續向前預取約 30 秒，低水位 3 秒；可暫停與恢復自己控制的播放。 |
| 播放中背景校時 | 優先處理目前位置，逐步提供完成成果，完全不控制播放。 |
| 整首校完再使用 | 按時間順序處理；全部必要時間完成才切換 overlay，部分成果仍可編輯。 |

使用者手動暫停會撤銷自動恢復資格；手動播放不被同一等待事件反覆暫停。模型初次載入上限 120 秒，每次緩衝等待與音訊區間取得上限 90 秒，單次推論 30 秒，全工作 10 分鐘，模型閒置 5 分鐘釋放。取消、切模式、切影片與頁面關閉會清理在途工作。切模式先等舊工作停止，再以目前已完成時間開始新工作；不改全域設定。

音訊透過靜音輔助播放器漸進取得，使用 WebM／Opus 原生 WebCodecs 解碼至 16k mono；一般視窗 26 秒，邊界擴展最多 30 秒。壓縮資料及 PCM 快取各上限 64 MiB。暫時仍依賴第二播放器；主播放器優先的混合取得尚未實作。

廣告播放時停止收音與跳轉，廣告音訊不進模型、不計歌曲覆蓋；廣告結束後核對影片、音源、時間軸及新初始化資料。舊 generation 資料不能提交。廣告期間停止 15 秒無進度判定，但不延長區間 90 秒及全工作期限。`mediaKeys` 附掛只是診斷，實際加密音訊另外判斷。無法確認安全來源時保留結果並失敗，不假裝接續成功。

## AI 服務設定

填入 Base URL（例如 `https://your-service.example/v1`）、API Token，必要時成對填入 Cloudflare Access Client ID／Secret；載入模型、選取後儲存。來源預設提供 LRCLIB，可新增網域及選擇子網域。

設定來源及全網搜尋要求 AI server 支援 Responses API 的 `web_search` 工具。留言路徑改由擴充功能先讀取目前影片實際載入的頂層留言，再經 `chat/completions` 請 AI 選出歌詞，不要求 AI 自行開啟留言。讀取最多等待 15 秒，最多 20 則、單則 24,000 字元、合計 64,000 字元，優先呈現置頂；必要時暫時捲至留言區觸發載入。這不是全留言爬取。候選必須通過留言 ID、來源 URL 與原文順序比對，才可採用。讀取失敗不轉交 AI 猜測；各路失敗不影響其他路徑。AI 按鈕明示使用額度；設定頁的搜尋測試另外確認送出。模型清單查詢上限 8 秒，不自動重試。

憑證保存在這台電腦的擴充功能可信儲存，不同步、不傳給 YouTube、不放入 prompt 或 SRT。請使用可獨立撤銷的 Token。未設定 AI 仍可使用人工 YT 字幕、貼入、本機補時、手動校時與保存／匯出。

## 保存、預覽與限制

編輯頁可手動改時間、排除句子、查看待處理項目、設定整體偏移及顯示方式。保存結果與舊版本相容；從本機載入不呼叫模型。原文／雙語／僅譯文顯示及 SRT 匯出保留；譯文不足時不能以雙語或僅譯文保存／匯出，本次沒有新增翻譯請求。

- Whisper-base 對歌曲、日文漢字／假名、伴奏及重複副歌可能無法可靠定位。歧義或弱證據保留待處理；可手動補時或排除後保存。
- 影片版本或剪輯不同時，來源自帶時間碼不保證適用，需自行核對。
- 不支援格式、加密音訊、網路或模型失敗保留文字與已完成時間。部分廣告返回同一受污染音源時會安全拒絕。
- MV3 背景重啟時無法安全接回本機 owner，顯示中斷後由使用者重試；不從舊快照恢復播放資格。已保存結果仍可用。
- 限桌面一般 watch 頁；不支援手機、Firefox、Shorts、直播、嵌入影片、原生子母畫面、逐字卡拉 OK。影片硬字幕無法移除。
- 本機結果上限 100 MiB，不自動刪除手動成果，不提供帳號或雲端同步。

## 開發與驗證

```powershell
npm ci
npm test
npm run typecheck
npm run build
npm run test:e2e
npm run package
```

本機環境 npm 不在 PATH 時可用 `node .tools/package/bin/npm-cli.js` 執行相同命令。E2E 使用獨立暫存 profile 與 localhost 假 AI，結束清理，不操作使用者登入瀏覽器。真實 WASM 測試需要忽略目錄中的既有模型及音訊素材；缺少時明示 skip，不冒充推論成功。建置與 ZIP 不含測試憑證或測試 manifest 的 localhost 固定權限。

`node scripts/verify-progressive-youtube.mjs` 為單影片、90 秒、零重試、零 AI 的真實解碼 smoke；舊驗證文件記錄的是當時版本，請以本次驗收文件理解目前能力。程式未複製 asbplayer 的 AGPL 原始碼；套件各自授權保留。

`node scripts/verify-youtube-comments.mjs` 會使用忽略的 `ai-server.payload` 呼叫一次真實 AI，以指定影片的真實置頂留言驗證讀取、分析與採用；需事先建置，並備有 E2E 的 Brave 與本機模型。此測試將其他搜尋路徑隔離為本機回覆，單一 AI 請求上限 120 秒、零重試，整體上限 180 秒。請求／回覆與截圖只存於忽略的 artifacts，憑證不寫入瀏覽器。成功證據與限制見[原生留言驗收](docs/validation/2026-10-21-native-comments.md)。
